# Зарница — оценка команды

PWA для оценки команды и участников по нормативам «Зарницы». Работает офлайн.

## Установка на телефон (через GitHub Pages)

1. Создайте публичный репозиторий на GitHub.
2. Загрузите файлы: `index.html`, `manifest.json`, `sw.js`, `icon.svg`, `README.md`.
3. Откройте **Settings → Pages**:
   - Source: `Deploy from a branch`
   - Branch: `main`, папка `/ (root)`
   - Сохраните, дождитесь публикации.
4. Откройте ссылку вида `https://ВАШ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/` на телефоне.
5. **Установить на экран «Домой»**:
   - Android / Chrome: меню → «Установить приложение»
   - iPhone / Safari: «Поделиться» → «На экран Домой»

После установки приложение работает офлайн, данные хранятся на устройстве.

## Как пользоваться

- **Участники** — список команды и всех участников. Тапните по имени — откроются все нормативы с полями для заметок.
- **Свободный текст** — в каждом нормативе просто пишите свои наблюдения: сильные стороны, слабые, замечания, план исправления. Всё сохраняется автоматически.
- **Настройки (⚙)** — добавить/изменить/удалить участников и категории, изменить название команды, экспорт/импорт данных, сброс.

## Перенос данных между устройствами

- **Экспорт JSON** — сохраните файл (например, в облако).
- **Импорт JSON** — выберите файл на другом устройстве.

## Приватность

Никаких серверов, аналитики и аккаунтов. Всё хранится в `localStorage` вашего браузера.
